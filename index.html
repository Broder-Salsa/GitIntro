🚀 How to Get Your Cat on the Dance Floor

  1. 1
    Make sure you are on a fresh branch: 
    git switch -c add-cat-YOUR_GITHUB_USERNAME
  2. 2
    Copy the template into your own cat file: 
    cp cats/TEMPLATE.json cats/YOUR_GITHUB_USERNAME.json
  3. 3
    Customize your cat's JSON properties:
    • breed: calico, tuxedo, ginger, siamese, void, neon
    • dance_style: breakdance, bounce, spin, moonwalk, disco, headbang, robot, wiggle
    • accessory: sunglasses, party-hat, headphones, gold-chain, bow-tie, crown, none
    • favorite_color: hex code or CSS color (e.g. #00FFCC, hotpink)
    • catchphrase: Your cat's meow mantra!
  4. 4
    Commit and push your branch: 
    git add cats/YOUR_GITHUB_USERNAME.json
git commit -m "feat(cats): add YOUR_GITHUB_USERNAME to the dancefloor"
git push -u origin add-cat-YOUR_GITHUB_USERNAME
  5. 5
    Open a Pull Request on GitHub:

    Wait for the Instructor (Tech Lead) review, respond to any requested changes, and once merged, run:

    git switch main
git pull origin main

    Refresh this page to see the entire class dance together! 🎉
